# DevForge — лабораторные работы по Vue.js и Tailwind CSS

DevForge — цельный учебный проект онлайн-школы на Vue 3 и Tailwind CSS 3.4. Требования лабораторной применены непосредственно к главной странице и кабинету управления, без отдельной демонстрационной страницы и без Bootstrap.

## Запуск

Нужен Node.js и npm. В терминале из папки проекта выполните:

```bash
npm install
npm run dev
```

Vite выведет адрес локального сайта. Главная страница доступна по `/`, кабинет управления — по `/admin.html`. Для production-сборки: `npm run build`.

Демо-вход: `admin@devforge.ru` / `1234`.

## Vue-компоненты

- `src/App.vue` — состояние приложения, асинхронная загрузка таблиц и журнал действий.
- `src/SiteApp.vue` — главный лендинг, каталог с фильтрами, тарифы, заявка и чат поддержки.
- `src/components/AuthPanel.vue` — вход, регистрация и восстановление пароля.
- `src/components/ExcelImporter.vue` — выбор файла и drag-and-drop.
- `src/components/CourseTable.vue` — таблица, поиск, страницы и действия с курсами.
- `src/components/CourseModal.vue` — общее модальное окно создания и редактирования.
- `src/components/FilePanel.vue` — список импортированных файлов.
- `src/components/ChangeLog.vue` — журнал и сравнение состояния до/после.

## Как применены задания Tailwind

- Главная: sticky-навигация, hero, адаптивный каталог, профиль наставника, отзывы, тарифы, FAQ, footer, dark mode, чат и многошаговая заявка.
- Кабинет: sidebar, topbar, аналитические карточки, график, операции, таблица курсов, импорт файлов, Kanban и журнал изменений.
- Общие компоненты, цвета, кнопки, поля и состояния описаны через `tailwind.config.js` и `@layer components` / `@apply`.
- Интерфейсы выполнены mobile-first и адаптированы для ширины от 320 px.

## Функции

- Импорт `.xlsx`, `.xls`, `.csv`, `.tsv`, `.ods`. CSV и TSV декодируются как UTF-8. Для Numbers файл `.numbers` сначала экспортируется через «Файл → Экспортировать в → CSV» или «Excel».
- Шаблон таблицы: [templates/kursy-dlya-importa.csv](templates/kursy-dlya-importa.csv). Он открывается в Numbers и содержит подходящие заголовки.
- В таблице можно создавать, редактировать и удалять курсы; есть поиск, постраничный просмотр по 10 строк и кнопка подгрузки следующих строк.
- Исходные таблицы сохраняются в IndexedDB; курсы и журнал — в localStorage.

## Ограничения учебной версии

Сервер, база данных, настоящая отправка почты и восстановление пароля не настроены. Авторизация и сохранение данных локальны для браузера. Зависимости Vue, Vite и SheetJS устанавливаются командой `npm install`.

## Рекламный плейсхолдер

Компонент `src/components/AdSlot.vue` поддерживает форматы `banner` и `sidebar`, а также произвольные `width` и `height`. Баннер размещён на главной странице между каталогом курсов и блоком наставника.

## Проверка production-сборки

```bash
npm ci
npm run build
```

В папке `dist` должны появиться `index.html`, `admin.html`, папка `assets` и изображения. Папка `dist` не добавляется в Git: хостинг соберёт её автоматически.

## Публикация в Cloudflare Pages

1. Загрузить проект в GitHub-репозиторий.
2. В Cloudflare открыть **Workers & Pages**, создать Pages-проект и подключить GitHub.
3. Выбрать production-ветку `main`.
4. Указать **Build command**: `npm run build`.
5. Указать **Build output directory**: `dist`.
6. Запустить deployment и проверить `/`, `/admin.html`, изображения, тёмную тему и Vue-интерактивность.

Для адреса `*.pages.dev` в `vite.config.js` не нужно менять `base`: проект уже собирается от корня `/`.

## Обоснование выбора хостинга

Cloudflare Pages выбран как основной вариант: запросы к статическим файлам на бесплатном тарифе не ограничены, а лимит в 500 сборок в месяц многократно превышает потребности учебного Vue-проекта. В правилах Pages нет отдельного запрета на обычный рекламный блок, а Git-интеграция автоматически публикует каждое изменение из GitHub.

Подробное сравнение платформ находится в [HOSTING_COMPARISON.md](HOSTING_COMPARISON.md).
