# DevForge

Учебный проект онлайн-школы на Vue 3 и Tailwind CSS. Внутри есть лендинг с каталогом курсов и отдельный кабинет для управления данными.

## Запуск

Понадобятся Node.js и npm.

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес. Главная страница открывается по адресу `/`, а кабинет — `/admin.html`.

Демо-вход в кабинет:

```text
admin@devforge.ru
1234
```

## Что есть в проекте

- адаптивный лендинг с тёмной темой;
- каталог курсов с фильтрами и сортировкой;
- многошаговая форма записи;
- демо-чат с поддержкой;
- кабинет с таблицей курсов и журналом изменений;
- импорт CSV, TSV, XLSX, XLS и ODS;
- рекламный плейсхолдер с настраиваемым размером.

## Сборка

```bash
npm run build
```

Готовый сайт появится в папке `dist`. В сборку входят обе страницы: `index.html` и `admin.html`.

## Публикация

Проект можно развернуть на Cloudflare Pages прямо из GitHub:

```text
Build command: npm run build
Output directory: dist
```

Для адреса `*.pages.dev` дополнительная настройка `base` в Vite не нужна.

## Ограничения

Это клиентская демо-версия без сервера и базы данных. Авторизация и отправка форм имитируются, а данные хранятся в `localStorage` и `IndexedDB` текущего браузера.
